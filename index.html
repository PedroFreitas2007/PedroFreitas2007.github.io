    Projetos

    Uniesp Tech, sistema de gestão acadêmica

    Projeto acadêmico em Java e DevOps

    Reconstrução de um sistema de cadastro de alunos que guardava tudo em memória e não tinha testes nem deploy automatizado. O código foi separado em camadas, ganhou banco de dados, testes, integração contínua, container e monitoramento.

    • Java 21 em camadas (Controller, Service, Model e Repository), com validação de nome e CPF e persistência em PostgreSQL via JDBC
    • Testes unitários com JUnit 5 para as regras de cadastro
    • Pipeline de CI no GitHub Actions: build, testes e geração do .jar a cada push e pull request
    • Dockerfile multi-stage e docker-compose com PostgreSQL, com configuração para deploy no Railway
    • Endpoint /health que verifica a conexão com o banco, e logs com SLF4J
    Java 21MavenPostgreSQLJUnit 5DockerGitHub Actions

    Sistema de Apostas Inteligente

    Protótipo front-end

    Painel para analisar jogos de futebol das cinco principais ligas europeias e da Champions League. Reúne probabilidades por resultado, gols esperados pelo modelo de Poisson, Expected Value e stake sugerido pelo critério de Kelly para destacar as value bets.

    • Dashboard com ROI mensal e distribuição das previsões
    • Previsões por jogo, com filtro por liga e projeção de gols
    • Value bets ordenadas por EV, confiança ou Kelly, com odds por casa
    • Analytics com evolução da banca e desempenho por liga e por mercado
    • Painel de análise por IA com resposta em streaming
    ReactTypeScriptViteTailwind CSSRechartsRadix UI

    Esta versão usa dados de exemplo e a análise por IA é simulada. A integração com IA real e com dados ao vivo está em desenvolvimento.

    FitMuscle, mini-curso fitness

    Curso interativo em SCORM 1.2

    Mini-curso em quatro telas para quem quer perder peso ou ganhar massa muscular. Uma assistente em JavaScript estima o prazo para atingir a meta, e o curso segue com sugestões de treino e dieta e termina com o resumo da simulação.

    • Calculadora de meta que estima o prazo em semanas conforme o objetivo, perder peso ou ganhar massa
    • Navegação entre telas com transição e retomada da última tela visitada
    • Integração SCORM 1.2: envia ao LMS o tempo de sessão, a pontuação e o status de conclusão
    • Resumo final com opção de refazer a simulação
    HTMLCSSJavaScriptSCORM 1.2

    A assistente é um algoritmo em JavaScript que funciona sem internet, e não um modelo de IA.
